# System Perspective on Generative AI

In automation and robotics, generative AI typically functions as:

- A planning or reasoning assistant
- A code or configuration generator
- A decision-support tool for human operators

It does **not** replace:
- Deterministic control loops
- Safety interlocks
- Real-time perception pipelines

This course emphasizes architectural separation between:
- Generative reasoning layers
- Real-time execution layers
- Safety-critical components
