# Tooling Ecosystem

This course leverages publicly available Generative AI platforms,
primarily the Hugging Face ecosystem.

---

## Tooling Philosophy
- Focus on model exploration, not model training
- Use hosted APIs for rapid experimentation
- Avoid tool-specific lock-in in course design

---

## Notes

Detailed setup steps (accounts, tokens, etc.) are handled through
guided sessions and are intentionally excluded from this repository
to maintain long-term relevance.
