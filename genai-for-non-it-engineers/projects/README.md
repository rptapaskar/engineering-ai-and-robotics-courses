# Project Studio and Showcase

The project component focuses on **domain relevance and clarity of thinking**.

---

## Project Expectations
- Identify a domain-specific problem
- Select an appropriate GenAI model
- Design effective prompts
- Demonstrate a working interaction pipeline

---

## Evaluation Focus
- Correct problem framing
- Appropriate use of GenAI
- Awareness of limitations
- Clear demonstration and explanation

Technical novelty is secondary to **engineering judgment**.
