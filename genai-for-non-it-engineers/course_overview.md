# Course Overview

Generative AI has become widely accessible through pre-trained foundation models
that can generate text, images, audio, video, and structured outputs.

For non-IT engineers, the key challenge is not model creation but:
- Understanding capabilities
- Recognizing limitations
- Using GenAI responsibly in domain contexts

---

## Course Outcomes

By the end of this course, learners should be able to:

- Apply basic Python programming and libraries for GenAI exploration
- Understand terminology and components of Generative AI systems
- Use prompt engineering techniques to interact with GenAI models
- Explore multi-modal GenAI models (text, audio, image, video)
- Design domain-specific GenAI-based solutions
- Implement and demonstrate a GenAI solution using platforms such as Hugging Face

---

## Course Structure

The course follows a **progressive, lab-centric structure**:

1. Introduction and Playground
2. Experimentation with GenAI modalities
3. Domain-specific project studio
4. Showcase and demonstration

The progression prioritizes confidence and clarity over complexity.
