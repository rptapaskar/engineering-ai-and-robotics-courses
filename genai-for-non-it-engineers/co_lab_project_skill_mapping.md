# CO–Lab–Project–Skill Mapping  
## Generative AI for Non-IT Engineers

This document provides a structured mapping between **Course Outcomes (COs)**,
**laboratory activities**, **project work**, and **skill development** for the
course *Generative AI for Non-IT Engineers*.

The mapping is designed to ensure **clarity, traceability, and accreditation readiness**
while remaining aligned with the course philosophy of **system-level understanding
and responsible use of Generative AI**.

---

## Course Outcomes (COs)

| CO Code | Course Outcome |
|-------|----------------|
| CO1 | Apply Python programming fundamentals and essential libraries for Generative AI applications |
| CO2 | Explore and apply prompt engineering techniques for Generative AI applications |
| CO3 | Explore and apply Generative AI concepts for text, audio, image, and video modalities |
| CO4 | Develop domain-specific solutions leveraging Generative AI techniques |
| CO5 | Implement and demonstrate a domain-specific Generative AI solution using platforms such as Hugging Face |

---

## CO → Labs → Projects → Skills Mapping

| CO | Supporting Labs / Modules | Project Studio & Showcase Alignment | Skills Developed |
|---|---|---|---|
| **CO1** | GenAI Introduction & Playground<br>• Python fundamentals refresher<br>• Using libraries for GenAI interaction | Foundational capability required across all project work | • Python literacy for non-IT engineers<br>• Confidence in using APIs and notebooks |
| **CO2** | Prompt Engineering Exploration<br>• Prompt structuring techniques<br>• Iterative prompting strategies | Central to project interaction design and demonstration | • Prompt design thinking<br>• Clear human–AI interaction |
| **CO3** | Experimentation Lab (Multi-Modal)<br>• Text models<br>• Audio models<br>• Image models<br>• Introductory video models | Students select one or more modalities relevant to their domain problem | • Multi-modal AI awareness<br>• Capability and limitation analysis |
| **CO4** | Project Studio<br>• Domain problem identification<br>• AI suitability analysis | Core focus of project development | • Problem formulation skills<br>• Domain–AI alignment<br>• Engineering judgment |
| **CO5** | Showcase & Demonstration Labs<br>• Model selection<br>• Interaction pipeline walkthrough | Final project demonstration and explanation | • Platform usage (Hugging Face)<br>• Solution communication<br>• Responsible AI deployment |

---

## Mapping Rationale

- Laboratory activities emphasize **confidence building and conceptual clarity** rather than software specialization.
- Project work prioritizes **domain relevance, correctness of problem framing, and responsible AI use**.
- Skill development focuses on **engineering reasoning**, **AI literacy**, and **system-level thinking**.

This mapping ensures that:
- Each Course Outcome is explicitly supported
- Assessment alignment is transparent and defensible
- The course is portable across multiple non-IT engineering disciplines

---

## Alignment with Course Philosophy

The mapping reflects the core philosophy of the course:

> Generative AI is a supporting system capability that must be applied judiciously,
> validated carefully, and integrated responsibly within engineering systems.
