# Domain-Specific Project Themes  
## Automation and Robotics  
### (GenAI for Non-IT Engineers)

This document outlines **representative project themes** for students from
Automation & Robotics and allied engineering disciplines undertaking the course
*Generative AI for Non-IT Engineers*.

The project themes emphasize **system thinking, correct problem formulation,
and responsible use of Generative AI**, rather than model development.

---

## Project Design Philosophy

Projects are designed to:
- Reinforce GenAI as a **supporting system component**
- Encourage **human-in-the-loop** and supervisory architectures
- Avoid replacing deterministic control or safety logic
- Build confidence in applying GenAI responsibly

---

## Theme 1: GenAI-Assisted Robot Task Planning

### Problem Context
Robotic task planning often involves translating high-level objectives
into structured action sequences.

### GenAI Role
- Assist in generating task plans from natural language descriptions
- Support sequencing and reconfiguration of tasks

### Example Applications
- Assembly task sequencing
- Pick-and-place workflow description
- Human-readable task specification

### Key Learning Focus
- Separation of planning assistance from execution control
- Validation of generated plans before execution

---

## Theme 2: Human–Robot Interaction (HRI) Support Using GenAI

### Problem Context
Effective human–robot collaboration requires clear communication
and interpretability.

### GenAI Role
- Interpret natural language instructions
- Generate explanatory feedback for robot actions

### Example Applications
- Operator instruction interpretation
- Explanation of robot decisions
- Assistive dialogue systems

### Key Learning Focus
- Trust and transparency
- Limitations of natural language understanding in safety-critical systems

---

## Theme 3: GenAI-Assisted Robot Programming Support

### Problem Context
Programming industrial and research robots can be time-consuming
and error-prone for non-expert users.

### GenAI Role
- Generate code templates or pseudocode
- Assist with configuration and parameter explanation

### Example Applications
- Robot motion script scaffolding
- Parameter tuning explanations
- Documentation generation

### Key Learning Focus
- GenAI as an assistant, not an autonomous programmer
- Importance of human validation and testing

---

## Theme 4: Perception Pipeline Documentation and Analysis

### Problem Context
Robotic perception pipelines are complex and often poorly documented.

### GenAI Role
- Summarize perception pipeline behavior
- Assist in interpreting perception outputs

### Example Applications
- Vision pipeline explanation
- Sensor data interpretation
- Failure mode narration

### Key Learning Focus
- Explainability in robotic perception
- Avoiding over-reliance on generated interpretations

---

## Theme 5: Maintenance and Diagnostics Support for Robotic Systems

### Problem Context
Robotic systems require regular maintenance and fault diagnosis.

### GenAI Role
- Assist in interpreting logs and alerts
- Generate maintenance checklists

### Example Applications
- Diagnostic report summarization
- Maintenance procedure assistance
- Fault description clarification

### Key Learning Focus
- Human-in-the-loop diagnostics
- Reliability and responsibility boundaries

---

## Theme 6: Simulation and Digital Twin Assistance

### Problem Context
Simulation and digital twins are widely used for robotics validation.

### GenAI Role
- Assist in configuring simulation scenarios
- Explain simulation outcomes

### Example Applications
- Simulation setup guidance
- Result interpretation summaries
- Scenario variation suggestions

### Key Learning Focus
- Fidelity awareness
- Difference between simulated and real-world behavior

---

## Theme 7: Safety and Risk Awareness in Automation Systems

### Problem Context
Automation systems operate under strict safety constraints.

### GenAI Role
- Assist in identifying potential hazards
- Support safety documentation and reviews

### Example Applications
- Risk assessment summaries
- Safety checklist generation
- Incident report assistance

### Key Learning Focus
- GenAI limitations in safety-critical decision-making
- Responsibility and accountability

---

## Project Evaluation Emphasis

Projects are evaluated based on:
- Correctness of problem framing
- Appropriate placement of GenAI within the system
- Awareness of limitations and risks
- Quality of explanation and demonstration

Technical novelty is **secondary** to engineering judgment.

---

## Expected Outcomes

By completing these projects, students should demonstrate:
- Ability to integrate GenAI responsibly into automation and robotics contexts
- Improved communication between human operators and robotic systems
- System-level reasoning rather than tool-centric thinking

---

> These project themes aim to prepare Automation & Robotics students
> to engage with Generative AI **confidently, critically, and responsibly**.
